# Git & GitHub — Quick Reference Guide

A concise, practical guide to Git and GitHub — what they are, how they differ, and the commands you'll actually use day to day. Written up as a PDF report, originally for coursework, and shared here for anyone learning version control from scratch.

📄 **[Read the full PDF guide](./Git_and_GitHub.pdf)**

## What's inside

- **Git vs GitHub** — the tool vs. the platform, explained clearly
- **Why they're used** — the real problems they solve (no more `project-final-v2-reallyfinal.docx`)
- **Installation** — step-by-step Git setup on Windows
- **Basic Git config** — `user.name` and `user.email` setup
- **Getting started** — `git init`, connecting to GitHub, cloning repos
- **Core commands cheat sheet** — `add`, `commit`, `push`, `pull`, `branch`, `merge`, and more
- **GitHub features** — pull requests, issues, Actions (CI/CD), repo management
- **Pros & cons** — honest tradeoffs of both tools
- **Real-world use cases** — from open-source projects to student portfolios

## Who this is for

Beginners who keep hearing "just push it to Git" and want an actual explanation — plus a handy reference for anyone who forgets the difference between `checkout` and `switch` (again).
